# Security policy

This template has no hosted service. A vulnerability in the sample Electron app, build configuration or release workflow may still affect projects built from it.

Please report security issues through GitHub's **Security → Report a vulnerability** option, if the repository has private vulnerability reporting enabled. Maintainers should enable that option before public launch and add a private contact method here if their GitHub plan does not support it. Do not post exploit details in a public issue.

Only the latest tagged version of this template is maintained. Projects created from it should keep Electron, electron-builder and GitHub Actions dependencies updated independently.
